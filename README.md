# Label Print · Lalitha Naturals

Design and print product labels (50×50, 25×50, 100×150 mm), rack tags and 80 mm thermal slips — straight from the browser.

**Open it:** after GitHub Pages is switched on, the app is at
`https://<your-github-username>.github.io/<repository-name>/`

## Put it on GitHub (one time, about 5 minutes)

1. Sign in at github.com and click **New repository**. Name it, for example, `label-print`. Choose **Public**, then **Create repository**.
2. On the new repository page click **uploading an existing file**.
3. Drag in all the files from this folder: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`. Click **Commit changes**.
4. Go to **Settings → Pages**. Under *Branch* choose **main** and **/ (root)**, then **Save**.
5. Wait 1–2 minutes. The link appears at the top of the Pages settings.

## Use it like an app

- **Android (Chrome):** open the link → menu ⋮ → **Add to Home screen** / **Install app**.
- **iPhone (Safari):** open the link → Share → **Add to Home Screen**.
- **Mac / PC (Chrome or Edge):** open the link → click the install icon in the address bar.

After the first visit it also opens without internet (fonts need internet the first time).

## Updating

Replace `index.html` with the new version (Add file → Upload files), and in `sw.js` change `label-print-v1` to `label-print-v2` so phones pick up the update.

## Good to know

- Designs, saved products and settings are stored **in each browser/device**. Use **Settings → Export backup** on one device and **Import backup** on another to copy them.
- Printing works to any printer the device can reach (USB, Wi-Fi, AirPrint). For thermal auto-cut, set the printer's own option **Cut: after each page** once.
- The repository is public, so anyone with the link can open the page. Your saved data is not uploaded — it stays on your device.
